# 🔬 Research Multi-Agent Team

A modular multi-agent research assistant built with CrewAI, Streamlit, and Groq GPT-OSS 120B.

## 🤖 Agents

1. Research Scout
2. Academic Researcher
3. Evidence Reviewer
4. Research Writer

## 🛠️ Technologies

- Python
- CrewAI
- Streamlit
- Groq
- GPT-OSS 120B
- Wikipedia API
- OpenAlex
- Crossref

## 🔄 Workflow

User Topic
↓
Research Scout
↓
Academic Researcher
↓
Evidence Reviewer
↓
Research Writer
↓
Final Research Report

## 🚀 Deployment

The project is designed for deployment on Streamlit Community Cloud using GitHub.
